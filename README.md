# 大衍 · 周易占卜

一个用于日常起卦与自省的轻量级周易网页应用。支持蓍草、三枚铜钱、梅花报数与梅花时间四种方法，无需注册，问题和记录只保存在当前浏览器中。

**在线体验：** [dayan-iching.pages.dev](https://dayan-iching.pages.dev/)

> 本项目用于周易文化研究与个人参考，不构成医疗、法律、投资或其他专业建议。重大决策请结合现实信息独立判断。

## 功能

- 大衍筮法：以 49 根蓍草、三变成爻的方式生成六爻
- 三枚铜钱：逐次掷钱六次，或一键完成；字面为 2、背面为 3
- 梅花报数：报一个正整数，配当前北京时间时辰起卦
- 梅花时间：默认当前时间，也可指定公历日期时间；自动换算农历
- 分步演算：逐爻展示起卦过程，保留仪式感而不牺牲可读性
- 卦象解读：展示本卦、变卦、动爻、卦辞与爻辞
- 传统取用：覆盖 0–6 个变爻的取用规则，并附简要说明
- 梅花参考：本卦、互卦、变卦，以及体用、五行关系和可展开的计算依据；白话提示来自固定规则，不是 AI 预测
- 明暗主题：支持浅色与暗色界面
- 本地记录：最多 40 条，保存方法、规则版本、输入和取时；兼容旧蓍草记录
- 隐私分享：默认不含所占之事和起卦依据，两项可独立选择公开；兼容旧分享链接
- 响应式：桌面方法侧栏、手机方法切换；首次选择，之后记住最后一次完成的方法

## 梅花时间约定

固定北京时间（UTC+8），按农历月日、年支与时辰计算。零点换日、春节换年，闰月沿用同月数；子时为 23:00–01:00，不在 23:00 提前换日。支持公历 1901–2099 年，取时在开始起卦时锁定。

报数接受 1–999999999999 的正整数：数字取上卦，时辰取下卦，二者合数取动爻。时间法以年支数＋月数＋日数取上卦，再加时辰数取下卦与动爻。卦以八除、爻以六除，余零取八或六。

依据 [《梅花易数》卷一](https://zh.wikisource.org/zh-hant/梅花易數/卷一) 与 [卷二](https://zh.wikisource.org/wiki/梅花易數/卷二) 的相关起例和体用参考，日期边界采用本应用明确公开的约定，不代表唯一流派。

## 隐私说明

应用没有账号、服务端数据库或第三方分析服务。所占之事与历史记录默认只保存在浏览器的 `localStorage` 中；清除浏览器站点数据会同时删除这些记录。分享链接默认仅编码六爻、方法和规则，不包含问题、报数或时间。勾选公开后，这些信息会直接写入链接；编码不是加密，任何获得链接的人都可以读取。打开分享不会改变本机记住的起卦方法。

## 技术栈

- React 19 + TypeScript
- Vite
- Motion 与 Radix UI
- lunar-javascript 1.7.7（固定版本的公历／农历换算）
- Node.js 内置测试运行器
- Cloudflare Pages

核心起卦逻辑位于 [`web/src/divination.ts`](web/src/divination.ts)，卦爻辞数据位于 [`web/src/data/gua_yao_ci.json`](web/src/data/gua_yao_ci.json)。旧 Python demo 已在 Web 版本稳定后移除，算法对应关系由自动化测试继续保障。

## 本地开发

建议 Node.js 22.18 或更高版本（逻辑测试使用 Node 内置 TypeScript 类型擦除）。

```bash
cd web
npm ci
npm run dev
```

Vite 会输出本地访问地址，通常为 `http://localhost:5173/`。

## 测试与构建

```bash
cd web
npm run test:logic
npm run check:runtime
npm run test:sites
npm run build
```

生产文件输出到 `web/dist/client`。
