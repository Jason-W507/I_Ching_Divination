# 多种周易占卜方法：设计访谈

更新日期：2026-10-03。状态：用户选择方案 2，已完成本地实现、测试和浏览器视觉／交互验收，并批准发布至现有 Cloudflare Pages 项目。验收见 `web/design-qa.md`；实际发布状态以 GitHub 提交的 Cloudflare Pages 检查为准。

## 已确认

- 产品目标：日常起卦与自省。提供几种易上手的方法、清楚的操作说明和卦象阅读参考。
- 首批入口：保留大衍蓍草法，新增三枚铜钱法、梅花报数和梅花时间起卦。
- 铜钱交互：逐次掷钱＋一键完成。默认逐次点击六次，也支持一次完成。
- 梅花报数：一个数＋当前时辰。数字定上卦，时辰定下卦，两者之和定动爻。
- 梅花时间：默认当前日期时间，允许用户修改以复盘指定时刻。
- 时间规则：两种梅花入口统一固定北京时间，按农历月日、年支和时辰计算；公历输入自动换算，零点换日、春节换年、闰月沿用同月数，并公开说明所采用约定。
- 方法入口：首次使用选择方法；后续直接显示上次使用的方法及输入框，通过控件切换方法。
- 梅花结果：简明说明＋可展开细节。先显示卦象与基于固定规则的白话阅读提示，展开查看互卦、体用、五行关系与计算依据。
- 本地记录保存完整依据：起卦方法、报数、取时时刻、规则及卦象；分享默认精简，仅保留卦象、方法与复现所需规则，可另行勾选公开起卦依据。所占之事仍默认不公开。
- 产品名称改为“大衍 · 周易占卜”。
- 沿用现有网页应用，并保持桌面与手机适配、浅色与暗色主题。

## 当前基线

- 唯一起卦方法为大衍蓍草法；逐爻展示后呈现本卦、变卦与卦爻辞。
- 阅读参考按动爻数量选取卦爻辞；没有纳甲、世应、六亲等排盘字段。
- 历史记录和分享链接保存六个爻值，目前没有起卦方法或规则版本信息。
- 当前版本没有账号、后端或 AI 解读。

## 整体回顾已确认的交互细节

- 将“上次使用”定义为本设备上最后一次完成起卦的方法；临时切换、历史回看及打开分享链接不改变默认方法。
- 已有有效蓍草历史的用户默认继续进入蓍草页，新用户首次选择方法。
- 报数只接受正整数，对零、负数、小数或空输入给出清楚提示。
- 起卦前展示取时预览，点击起卦时锁定实际采用的北京时间与时辰；结果、历史回看和分享不随当前时间重算。
- 梅花时间使用用户确认的日期时间；在合法支持范围外的日期给出提示。
- 历史记录与旧分享链接继续可读；旧数据没有方法信息时按蓍草法解释，不制造原数据没有保存的推演细节。
- 继续采用已有的本地保存、简体界面、经典原文和明暗主题；白话提示来自固定规则与编辑内容。
- 桌面和手机各自验收首页、方法切换、起卦、结果与分享，保持现有响应式布局。

## 实现约定

- 农历换算锁定 `lunar-javascript@1.7.7`，显式传入 UTC+8 的公历字段，不依赖设备时区。
- 报数范围为 1–999999999999，避免浮点精度和无界输入。
- 铜钱字面 2、背面 3，独立等概率；6/9 为动爻。
- 历史沿用原有存储键，读取时校验并补全旧记录的方法，未保存的依据保持缺省。
- 分享使用 v2 载荷，兼容 v1；未知方法/规则和不一致依据不作为有效结果展示。
- 自动化测试涵盖经典观梅例、春节、闰月、子时、取模余零、四种方法、存储和分享隐私。

## 方法依据

- [俄勒冈大学 I Ching readings](https://hexadecimal.uoregon.edu/ching/explain.html)：蓍草与三钱均逐爻得到 6–9，并由下至上组成卦象。结合现有代码，可推断铜钱法能够共用卦象模型与经典文本。
- [《梅花易数》卷一](https://zh.wikisource.org/zh-hant/梅花易數/卷一)：包含卦以八除、爻以六除、互卦、年月日時起例及物数占例。时间规则须明确年支、月份、日期与时支的取法。
- [《梅花易数》卷二·体用](https://zh.wikisource.org/wiki/梅花易數/卷二#體用)：成卦后的阅读涉及本卦、互卦、变卦及体用关系。梅花结果需要专属内容，不能直接视作现有多动爻取辞流程的同义入口。
